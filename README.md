# 🏨 Online Hotel Reservation System Using Full Stack Java

## 📌 About the Project

The **Online Hotel Reservation System** is a web-based application developed using Full Stack Java technologies. It is designed to simplify the hotel booking process by allowing users to explore hotel services, make reservations, and manage their bookings online.

The main objective of this project is to provide a convenient and user-friendly platform for hotel reservation management.

## ⚙️ Installation and Setup

### Prerequisites

- Java JDK
- Eclipse IDE
- Apache Tomcat Server
- MySQL Database

### Steps to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/kabyasarkar01-tech/Online-Hotel-Reservation-System-Using-Full-Stack-Java.git
   ```

2. Open Eclipse IDE.

3. Import the project:
   - Go to File → Import.
   - Select Existing Projects into Workspace.
   - Browse to the cloned project folder.
   - Click Finish.

4. Configure the MySQL database.

5. Update the database connection details in the project configuration.

6. Configure Apache Tomcat Server in Eclipse.

7. Right-click the project and select Run As → Run on Server.

8. Open the application in your browser.
